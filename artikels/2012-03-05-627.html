Go4Solit nieuwe co-sponsor

2012-03-05 · Nieuws · Gepubliceerd · Artikel 627

Het SMO-Specialized Triatlonteam mag een nieuwe samenwerking aankondigen met de firma Go4Solit bvba.

Go4Solit is gespecialiseerd in het ontwikkelen van high-end java software voor server toepassingen. Go4Solit kan uw partner zijn voor zowel project management, analyse als ontwikkeling. De specialisatie ligt in het maken van zeer performante, beveiligde en uitbreidbare software oplossingen.
